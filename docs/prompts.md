PRD - TechDoc Coach

1. Product Vision

한국 개발자가 영어 기술 문서를 번역본에 의존하지 않고 스스로 읽고 이해할 수 있도록 돕는다.

우리는 문서를 번역하지 않는다.

우리는 사용자가 영어 원문을 읽고,
기술 개념을 이해하고,
실무에 연결하고,
스스로 설명할 수 있도록 훈련시킨다.

⸻

2. Problem

현재 개발자는 공식문서를 읽을 때 다음과 같은 문제를 겪는다.

1. 문서가 길다.
2. 기술 용어를 이해하기 어렵다.
3. 번역기를 사용하면 읽을 수는 있지만 실력이 늘지 않는다.
4. 이해했다고 생각하지만 실제로 설명하지 못한다.
5. 현재 프로젝트와 연결되지 않는다.

결과적으로 공식문서를 “소비”할 뿐 학습하지 못한다.

⸻

3. Product Goal

사용자가

“영어 기술 문서를 읽을 수 있다”

를 넘어서

“영어 기술 문서를 읽고 자신의 말로 설명할 수 있다”

상태에 도달하게 만든다.
